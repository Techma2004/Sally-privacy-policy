# Sally Privacy Policy

A simple static privacy policy website for Sally Bot.

## Overview

This repository hosts a clean, responsive privacy policy page for Sally Bot. It is designed to be easy to view, easy to host, and easy to customize for future updates.

## Files

- `index.html` – the privacy policy webpage
- `LICENSE` – repository license

## Local preview

Open `index.html` directly in a browser, or run a tiny local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Purpose

This project provides a clear and professional policy page explaining:

- what information is collected
- how it is used
- how it is stored
- user rights and controls
- security practices
- changes to the policy
- contact information

## Customization

You can update the content in `index.html` to match your bot's exact data practices, contact details, or jurisdiction-specific privacy requirements.
